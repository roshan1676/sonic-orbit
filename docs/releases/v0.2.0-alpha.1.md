# SonicOrbit Native 0.2.0-alpha.1

A new native Windows player with an offline installer. Local media playback, measured headphone rendering and CPU music preparation no longer need a browser, localhost server, Python installation, FFmpeg installation or a first-use model download.

## Included

- Native WPF interface, LibVLC decoding, WASAPI output, play/pause/stop, seeking, local-file dialog and drag/drop. AI preparation/cancellation controls stay visible while listening settings scroll. Opening another file clears the prior AI status; Space respects focused controls.
- Shared C++ stereo renderer with H3/H17 measured HRIR data, a screen-centre anchor, yaw preview, stage width, smooth coefficient changes, shared output headroom and linked sample-peak protection.
- Explicit S16N decoding at the VLC 3 callback boundary, converted to float before rendering. Tests check that a quiet fixture stays quiet and contains no invalid samples. Multichannel source audio is downmixed; this is not a bit-perfect high-resolution or Atmos decoder path.
- Bundled Spleeter four-stem ONNX graph and CPU inference runtime. Background preparation covers up to five minutes, caches results locally, supports cancellation and can mix prepared groups into a front stage. High frequencies above the model's analysis band are retained in the "other" group. Short inference segments and separation itself can produce artifacts.
- Native Windows output selection and endpoint-change notifications for connected wired/wireless audio devices. Manual lip-sync adjustment is available; actual Bluetooth hardware remains untested.
- Optional OpenTrack UDP yaw input on loopback port 4243, recentering and visible stale-data status. Normal Bluetooth connection/RSSI is never treated as head orientation.
- Per-user installer, portable ZIP, upstream VLC/LibVLCSharp source archive, bundled .NET and app-local Visual C++ runtime DLLs, offline dependency/model verification, notices, checksums and source/build documentation.

## Evidence

The C++ test executable exercises stereo headroom, profile validation, rotation and bounded finite output. Seven native integration checks cover real-profile P/Invoke processing, FFT reconstruction, OpenTrack packets, bundled ONNX inference/reconstruction, cancellation, LibVLC-to-WASAPI playback with pause/seek/resume and media-to-stems decoding without Python/FFmpeg. The generated quiet MP4 produced a decoded peak near 0.043 and rendered peak near 0.015, with zero invalid decoded samples and zero dropped frames in that short test. These values are fixture-specific, not audio-quality scores.

The exported magnitude graph was compared to TensorFlow on a deterministic probe: maximum absolute output difference below 3.2e-7. A generated two-second stereo signal reconstructed from four stems with relative RMS error about 7.1e-8. These establish conversion and mixture consistency, not source-isolation quality or listener preference.

The existing browser/extension regression suite is separate. Build-machine verification is not a clean-machine or Bluetooth compatibility certification. The setup executable is unsigned; no certificate has been purchased or implied.

## Scope

This release adds Windows Native. The browser player, Chromium extension, Web SDK and Android WebView APK remain at 0.1.0-alpha.2. Native camera tracking, pitch/roll rendering, Android native playback, mobile AI, native Unity/Unreal plugins, system-wide effects and sensor-specific Bluetooth head-tracker adapters remain future work. No demonstrated superiority over Dolby Atmos is claimed.
