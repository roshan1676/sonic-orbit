# SonicOrbit 0.1.0-alpha.1

The first public alpha packages the experiment as a local player and reusable browser renderer.

**Downloads:** Windows x64 portable player with Node runtime/native launcher; development-signed Android local-file player; unpacked Chromium tab extension; Web ES module with TypeScript declarations; illustrated documentation; SHA-256 checksums.

**Included:** Original/Spatial comparison, shared headroom and sample guard, tone controls, virtual headphone speakers and short room cues. The desktop adds optional four-group AI music separation, editable source placement, camera landmarks/setup guidance, measured-profile audition for AI objects and loopback OpenTrack input. The Web module accepts source height/distance and listener position/orientation with host-controlled routing.

**Baseline verification:** 31 automated tests and 25 browser checks. APK signature/build verification is complete. Actual extension capture and phone playback still need device validation. Release-specific checks and public CI status are recorded on GitHub.

**Limits:** stereo input/output; no Atmos metadata decoding/encoding; visible-face camera tracking; five-minute AI preview with artifacts/resource costs; no desktop AI/live tracking in extension/APK; Android foreground local files up to 1 GB; unsigned Windows launcher and development APK signing; native Unity/Unreal and system-wide routing still planned.

The packaged Node server/interface were exercised separately from the native launcher. Automatic approval review blocked running the newly compiled Windows launcher, so the launcher itself is not counted as runtime-tested.
